## About CMS

A CMS (Content Management System) is a powerful website content editor that allows you to manage your website's content easily. They provide a user-friendly interface for creating, editing, and organizing content without needing to modify the website's code directly.

## Compatibility

CMS is compatible with all DWS-made websites, including plain HTML websites and Node.js web-apps. CMS subscriptions are transferable between DWS-made CMS-compatible sites.

## Backups

All CMS instances are backed up daily, if your instance contains changes. Backups contain all models, data, assets, and settings. Contact us to restore a backup.
