## Reporting Issues

If you encounter any issues while using <Icon icon="/icons/commtrackr/commtrackr.svg" className="islight" /><Icon icon="/icons/commtrackr/commtrackr-dark.svg" className="isdark" /> **CommTrackr**, please follow these steps to report them:

1. **Check Existing Issues**: Before reporting a new issue, please check the [<Icon icon="github" /> GitHub Issues page](https://github.com/DangoWeb/CommTrackr/issues) to see if the issue has already been reported or addressed.
2. **Gather Information**: Collect relevant information about the issue, including:
   - A clear and concise description of the problem.
   - Steps to reproduce the issue.
   - Expected and actual behavior.
   - Any error messages or logs.
   - Your environment details (e.g., <Icon icon="node-js" /> **Node.js** version, <Icon icon="/icons/commtrackr/expressjs.svg" className="islight nomargintop" /><Icon icon="/icons/commtrackr/expressjs-dark.svg" className="isdark" /> **Express.js** version, session store used).
3. **Create a New Issue**: Go to the [<Icon icon="github" /> GitHub Issues page](https://github.com/DangoWeb/CommTrackr/issues) and click on "New Issue". Fill out the issue template with the information you gathered.
4. **Submit the Issue**: Once you have filled out the issue template, click "Submit new issue" to report the problem.

Our team will review the issue and respond as soon as possible. Thank you for helping us improve <Icon icon="/icons/commtrackr/commtrackr.svg" className="islight" /><Icon icon="/icons/commtrackr/commtrackr-dark.svg" className="isdark" /> **CommTrackr**!
