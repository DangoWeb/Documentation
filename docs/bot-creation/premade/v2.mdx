A simple yet useful bot with cool commands with embeds.

## Base Comands

- `avatar` View someones avatar!
- `beep` Responds with boop!
- `bookmark` Send something to yourself for later.
- `help` Help page to easily find the command you need!
- `kick` Kicks a user from your server.
- `message` Sends a message as the bot.
- `myrole` Shows your role information.
- `ping` Shows the bots ping!
- `poll` Starts a poll in your servers.
- `purge` Purges channel messages.
- `reload` Reload the bot.
- `restart` Restarts the bot.
- `server` Show server information.
- `stats` Show bot information.
- `status` Show bot status.
- `user-info` Show user information.
