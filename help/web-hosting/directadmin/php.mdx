## PHP Selector

<Icon icon="/icons/directadmin/php-selector.svg" /> **PHP Selector** is a tool in <Icon icon="/icons/directadmin/directadmin.svg" /> **DirectAdmin** that allows you to manage your PHP environment. It enables you to change the PHP version and activate or deactivate PHP extensions.

To access <Icon icon="/icons/directadmin/php-selector.svg" /> **PHP Selector**, follow these steps:

1. Log in to your <Icon icon="/icons/directadmin/directadmin.svg" /> **DirectAdmin** control panel.
2. Navigate to the **Advanced Features** section.
3. Click on <Icon icon="/icons/directadmin/php-selector.svg" /> **PHP Selector**. You will be redirected to the <Icon icon="/icons/directadmin/php-selector.svg" /> **PHP Selector** interface.
4. Select the required PHP version from the dropdown menu next to "Current PHP version".
4. Select required extensions from the alphabetical package list.

<Info>If you do not see the extension you need, [contact support](/help/support). The extension will need to be reviewed before it can be added.</Info>

## PHP Settings

The <Icon icon="/icons/directadmin/php.svg" /> **PHP Settings** tab in <Icon icon="/icons/directadmin/directadmin.svg" /> **DirectAdmin** allows you to configure various PHP settings for your web applications. This is particularly useful for developers who need specific PHP configurations for their applications.

To access <Icon icon="/icons/directadmin/php.svg" /> **PHP Settings**, follow these steps:

1. Log in to your <Icon icon="/icons/directadmin/directadmin.svg" /> **DirectAdmin** control panel.
2. Navigate to the **Account Manager** section.
3. Click on <Icon icon="/icons/directadmin/php.svg" /> **PHP Settings**.
4. Add new PHP setting overrides by searching for the override, selecting it, entering an override value, and clicking the **Add** button.
5. To remove an override, click the <Icon icon="trash-can" /> **Delete** button next to the override you want to remove.
