PHP websites are dynamic websites that use PHP as the server-side scripting language. PHP allows you to create interactive and data-driven websites, making it a popular choice for web development. In this guide, we will show you how to upload your PHP website on DirectAdmin.

## Upload Files

<Note>[FTP & SFTP](/help/web-hosting/directadmin/ftp) can be used instead of the online file manager.</Note>

Open your [DirectAdmin control panel](/help/web-hosting/directadmin/logging-in)'s <Icon icon="/icons/directadmin/files.svg" /> **File Explorer** and navigate to the `public_html` folder on the left. Your website files should appear in front of you.

Delete all files in the `public_html` folder and upload your website files to the `public_html` folder.

Once you have done that, close the <Icon icon="/icons/directadmin/files.svg" /> **File Manager** tab and reload your domain. The website template should be visible on your domain. If it does not appear when you reload the page, try accessing the domain on another browser or device, or clearing your browser's cache.

## Enable Required Extensions

Use the <Icon icon="/icons/directadmin/php-selector.svg" /> **PHP Selector** in DirectAdmin to enable the required PHP extensions for your website. You can find the <Icon icon="/icons/directadmin/php-selector.svg" /> **PHP Selector** in the **Advanced Features** section of your DirectAdmin control panel.
